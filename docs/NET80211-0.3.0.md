# MT7902 net80211 runtime candidate 0.3.0

This experimental x86_64 kernel extension connects the official OpenIntelWireless
net80211 stack to the MT7902 PCIe backend. It replaces the old connection and WPA2
supervisor in this build. Host tests, compilation, dependency auditing and kernel
bundle linking are automated. Loading, joining and traffic on hardware remain
unverified. This is not a confirmed fix for the Ramos router.

The bridge supports visible open or WPA2-PSK/CCMP networks, legacy a/b/g rates,
channels 1–11 and 36/40/44/48/149/153/157/161/165. WPA3, required PMF, HT/VHT/HE,
QoS/aggregation and long-slot 2.4 GHz operation are not implemented in this first
bridge. It is an Ethernet interface controlled by HeliPort-MT7902 2.1.5 (ABI v1).
Both MT7902 firmware files are embedded. No old Apple networking kext is needed.

## Install once, test several networks in the same boot

1. Keep your previous working EFI/kext as a recovery copy. Extract this ZIP.
2. Replace `EFI/OC/Kexts/itlmt7902.kext` with the complete bundle in this package.
   Keep only one enabled MT7902 driver. In OpenCore `Kernel -> Add`, use
   BundlePath `itlmt7902.kext`, ExecutablePath `Contents/MacOS/itlmt7902`,
   PlistPath `Contents/Info.plist`, Enabled true.
3. This candidate defaults to connection stage 3. No new boot argument is needed.
   An existing explicit `mt7902_stage=1` or `mt7902_stage=2` still overrides that
   default; remove that override for connection testing. Reboot once.
4. Run your current HeliPort-MT7902 2.1.5. Check the loaded engine with:

```sh
ioreg -r -c itlmt7902 -l -w0
```

Expect `port-version = 0.3.0-net80211`, `connection-engine = net80211`, and
`join-supported = Yes`. Test a phone hotspot first, then Ramos-5G and Ramos-2.4G.
Disconnect before switching networks. Each new join quiesces and recovers the
radio before creating a fresh stack session, so these tests do not require
separate OS reboots. A failed physical DMA quiescence stops further radio work.

For each attempt, note whether the app reaches connected, whether macOS gets an
IP address, and whether a webpage loads. `connected` alone is not an Internet
test. Collect diagnostics with the included script:

```sh
bash collect-logs.sh
```

Keep passwords out of diagnostic messages. This candidate does not include an
app update or change the HeliPort interface.

## Build and source

The package carries build evidence, exact driver/upstream source archives,
the staged PAE source modification, original copyright/license notices and
firmware licenses. See `SOURCES/BUILD.txt` and `build-manifest.json`.
The final kernel imports are recorded; target Tahoe KPI export/load verification
has not been performed. Retain the previous kext until hardware testing passes.
